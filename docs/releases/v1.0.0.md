# Slot Vision 1.0.0

Slot Vision is a native decorative slot machine screensaver with original dimensional cabinets, moving reels, simulated winning outcomes and flying gold coins. It contains no wagers, stored currency or purchases.

## Upgrade guide

This is the first release. Download `slot-vision.apk` and `slot-vision.apk.sha256`, verify their checksum, then install using `python3 install.py --serial TV_IP:5555`. Open the app to choose its game and appearance, then select Slot Vision through the TV screensaver settings or Fire TV Toolkit. Android API 23 and OpenGL ES 3 are required. No account, configuration file or migration is needed.

Later updates signed by the same release key retain local preferences. Before removal, choose another screensaver, then run `python3 install.py --serial TV_IP:5555 --uninstall`. Removing the application deletes its preferences. The standalone installer does not change device timers or screensaver selection. See the [installation guide](https://github.com/jeremykenedy/slot-vision/blob/v1.0.0/docs/INSTALLATION.md).

## Breaking changes

None. This release establishes package `com.jeremykenedy.reelatrium`, its DreamService and its local visual settings provider.

## Major changes

- Classic three reel cabinet with traditional BAR and 7 artwork and a center payline.
- Five reel palace with five paylines and a five row garden with five horizontal paylines.
- Spring, summer, autumn and winter artwork on the themed machines, with seasonal cabinet trim.
- Private lounge and casino surroundings.
- Continuous front camera orbit with independent target movement and a large cabinet framing.
- Simulated outcomes that settle on the actual symbols, proportional instanced gold coin bursts and a pulsing jackpot beacon.
- Remote settings for game, season, reel speed, lighting, camera movement and background, including independent random choices.

## Minor changes and fixes

Models, textures and lighting maps are bundled. The app requests no Android permissions, contains no runtime network client and has no tracking or analytics. The computer installer verifies release checksums and restricts download locations. Runtime and asset licenses are included in the APK.

## Verification and limitations

Release publication requires the completed [device matrix and visual evidence](https://github.com/jeremykenedy/slot-vision/blob/v1.0.0/docs/VERIFICATION.md). Pure settings, outcome and installer logic have 100% line and branch coverage. Native rendering, framework behavior and lifecycle checks are documented separately.

The renderer uses a 1280x720 surface composed into the TV display. Screen captures at 1920x1080 do not imply native 1080 or 4K rendering. Camera movement reduces fixed imagery but does not guarantee prevention of image retention. Other TV models, unattended idle activation, reboot and sleep/wake persistence, native 4K and sustained thermals need their own physical testing. This is the first release, so no previous tag comparison exists.
